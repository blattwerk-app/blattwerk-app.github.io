# Blattwerk

Arbeitsblätter und Stundenplanungen für die Grundschule (Klasse 3 und 4, NRW): Mathematik, Deutsch, Sachunterricht und Englisch.

**Öffnen:** https://blattwerk-app.github.io

Blattwerk läuft komplett im Browser. Alle Arbeitsblätter, Bilder und Planungen werden nur lokal im Browser der Nutzerin gespeichert und nicht ins Internet übertragen.
